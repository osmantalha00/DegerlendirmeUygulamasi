# 📚 Movie / Series / Book Rating App

A simple web application built with **HTML, CSS, and JavaScript** that allows users to register, log in, and rate movies, series, and books.

## Features

* User registration and login
* Rating system
* Category-based listing
* LocalStorage-based data management

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage
